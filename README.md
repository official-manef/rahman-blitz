# MonEscrow

Presentasi web bergaya slide untuk konsep MonEscrow, dengan tagline **“Silence pays. Objection pauses.”** Repositori ini berisi halaman HTML dan aset visual; halaman tersebut bukan bukti bahwa layanan escrow atau backend telah diimplementasikan.

## Membuka presentasi

Tidak diperlukan langkah build yang diketahui dari repositori ini. Buka `index.html` langsung di browser.

Tidak ada `package.json` maupun skrip build/npm dalam repositori saat audit.

## Cakupan yang terlihat

`index.html` memuat gaya visual gelap, tata letak panggung rasio 16:9, transisi slide, dan elemen presentasi seperti area hero, bagian masalah, serta kolom perbandingan. Kode yang tersedia tidak cukup untuk memastikan seluruh isi presentasi atau cara mengoperasikan navigasinya.

Halaman mendeklarasikan bahasa dokumen sebagai Inggris. Tampilan menggunakan ukuran dan animasi CSS; kecocokan pada berbagai ukuran layar atau preferensi gerak perlu diperiksa di browser.

## Struktur repositori

- `index.html` — halaman presentasi.
- `logo-mark.svg`, `logo.svg` — aset logo.
- `three-phone-demo.png` — aset gambar.

## Batasan dan verifikasi

Repositori ini menunjukkan presentasi/prototipe visual, bukan implementasi layanan escrow. Tidak ada backend, alur transaksi nyata, atau hasil deployment yang dapat dipastikan dari berkas yang tersedia.

Tidak ada perintah pengujian yang tercantum pada scripts. README ini tidak menyatakan bahwa halaman telah diuji; untuk pemeriksaan manual, buka `index.html` di browser.
